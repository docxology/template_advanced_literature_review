# Advanced literature review documentation

The standalone template demonstrates a configurable, multi-phase review using
a tracked synthetic exoplanet-atmosphere corpus. It records which search phases
contribute each paper, then measures overlap, citation links, and descriptive
features of that corpus.

- [Quick start](quickstart.md) installs project dependencies and runs tests.
- [Architecture](architecture.md) explains code ownership and provenance.
- [Retarget the review](forking_guide.md) for a different topic or phase design.
- [Build the manuscript](rendering_pipeline.md) replays the fixture, generates
  figures, and renders and validates PDF and HTML with pinned Template tooling.
- [Manuscript source](manuscript/README.md) lists the sections, token inputs,
  configuration, and bibliography.
- [Output inventory](output_inventory.md) and [conventions](output_conventions.md)
  document generated evidence.
- [Troubleshooting](troubleshooting.md) and [FAQ](faq.md) explain common boundaries.
- [Contributor instructions](agent_instructions.md), [testing](testing_philosophy.md),
  [style](style_guide.md), and [token syntax](syntax_guide.md) cover maintenance.
- [Historical decisions](archive/README.md) preserve the project audit and backlog.

The synthetic figures and statistics describe pipeline behavior on the fixture.
An empirical review requires a separately verified corpus and study design.
